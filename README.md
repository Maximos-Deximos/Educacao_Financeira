# Educacao_Financeira
Reposotorio que armazenará as informações e codigos da aplicação web a ser desenvolvida

# Como contribuir:
Clonar o repositorio

 git clone https://github.com/Maximos-Deximos/Educacao_Financeira/edit/main

# Desenvolvedores de escopo:
Desenvolvedores de escopo podem adicionar suas pesquisa a Decs/escopo.md, podem adicionar os requisitos a Docs/requisitos.md
Mudanças de documentação podem ser comitadas direto na main

# Desenvolvedores de Front
Desenvolvedores de front poderão adiconar seus desenvolvimentos a branches de dev/front ou criar uma outra branch desde que ela siga este padrão:
dev/front/nome_da_feature/

# Desenvolvedores de Back
Desenvolvedores de back poderão adiconar seus desenvolvimentos a branches de dev/front ou criar uma outra branch desde que ela siga este padrão:
dev/back/nome_da_feature/

# QA
Poderão testar a aplicação quando a equipe de desenvolvimento acredirar que seu desenvolvimento está finalizado

# Workflow
Para que a proxima etapa de desenvolvimento seja feita, é necessário que as etapas passadas estejam finalizadas.
